COPY-PASTE QUICKSTARTS

Start with read-only calls. Sign only in the user’s wallet.

Examples below use canonical public endpoints and do not require project secrets. Package APIs can change by version; pin and review your dependency versions before production use.

cURL · Chain ID

curl -sS https://rpc.kriptoaman.com \
  -H 'content-type: application/json' \
  --data '{"jsonrpc":"2.0","id":1,"method":"eth_chainId","params":[]}'
Expected canonical Chain ID: 0x560c (22028).

Browser fetch · Latest blocks

const response = await fetch(
  'https://explorer.kriptoaman.com/api/v2/blocks'
);
const data = await response.json();
console.log(data.items?.[0]);

ethers v6 · Read provider

import { JsonRpcProvider } from 'ethers';

const rpc = 'https://rpc.kriptoaman.com';
const provider = new JsonRpcProvider(rpc, {
  name: 'kriptoaman',
  chainId: 22028
});

console.log(await provider.getBlockNumber());

viem · Public client

import { createPublicClient, http } from 'viem';

const client = createPublicClient({
  chain: {
    id: 22028,
    name: 'KriptoAman Mainnet',
    nativeCurrency: { name: 'KAM', symbol: 'KAM', decimals: 18 },
    rpcUrls: { default: { http: ['https://rpc.kriptoaman.com'] } }
  },
  transport: http()
});

console.log(await client.getBlockNumber());

Wallet onboarding

await window.ethereum.request({
  method: 'wallet_addEthereumChain',
  params: [{
    chainId: '0x560c',
    chainName: 'KriptoAman Mainnet',
    nativeCurrency: { name: 'KAM', symbol: 'KAM', decimals: 18 },
    rpcUrls: ['https://rpc.kriptoaman.com'],
    blockExplorerUrls: ['https://explorer.kriptoaman.com']
  }]
});
This asks the wallet to add the network. It must never request a seed phrase or private key.

Transaction confirmation

const hash = '0x...';
const tx = await fetch(
  `https://explorer.kriptoaman.com/api/v2/transactions/${hash}`
).then(r => r.json());

console.log(tx.status, tx.block);
