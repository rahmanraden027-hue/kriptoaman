JSON-RPC quick start

The RPC endpoint is POST-oriented. Browser CORS may intentionally be restricted; wallets and backend clients can use the endpoint directly.

curl -sS https://rpc.kriptoaman.com \
  -H 'content-type: application/json' \
  --data '{"jsonrpc":"2.0","id":1,"method":"eth_chainId","params":[]}'
curl -sS https://rpc.kriptoaman.com \
  -H 'content-type: application/json' \
  --data '{"jsonrpc":"2.0","id":2,"method":"eth_blockNumber","params":[]}'
