Public developer model

Use the public RPC for ordinary EVM reads and signed transaction broadcast from a wallet or backend. Use Explorer REST APIs for indexed blocks, transactions, addresses, tokens and verified-contract data.

Security boundary: public developer documentation does not expose validator administration, private RPC origins, signing keys, keystores, seed phrases, treasury credentials, or privileged namespaces.

Recommended development flow

  1. Read network.json and validate Chain ID.
  2. Probe eth_chainId and eth_blockNumber.
  3. Build read-only calls first.
  4. Connect a user wallet for signed transactions; never collect private keys.
  5. Confirm the transaction in Explorer.
  6. Verify deployed contracts using the supported verification configuration.

Core JSON-RPC methods

eth_chainId, eth_blockNumber, eth_getBalance, eth_getCode, eth_call, eth_estimateGas, eth_gasPrice, eth_getTransactionByHash and wallet-signed transaction submission are standard starting points. Availability remains governed by the public RPC gateway policy.
