What the buttons do

  1. Verify Explorer reads /developer/network.json, /api/v2/blocks, and /api/v2/stats.
  2. Add / Switch Wallet requests wallet_switchEthereumChain; if the wallet reports unknown chain 4902, it requests wallet_addEthereumChain.
  3. Connect Wallet requests account access with eth_requestAccounts, then checks eth_chainId.

Security boundary

This starter never asks for a seed phrase, private key, keystore password, validator credential, treasury credential, or other signing secret. It does not send a transaction. Any later write flow should be reviewed and signed inside the user’s wallet.
