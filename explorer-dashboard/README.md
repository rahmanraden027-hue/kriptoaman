# KAM Explorer public surfaces

This directory contains the narrow static presentation surfaces deployed in front of Blockscout for KriptoAman Mainnet. They are read-only and use public Blockscout/RPC evidence only.

Routes: `/`, `/stats`, `/tokens`, `/developer`, `/developers`, `/addresses`, `/validators`, `/contracts`, `/status`.

The underlying Blockscout API and detail routes remain authoritative and are not replaced by these files.
